# SQL Practice with MySQL

This repository contains my SQL practice while learning MySQL using MySQL Workbench. The exercises are based on a sample sales database consisting of customers, orders, and order items created by Mosh Hamdani.

The exercises cover essential SQL concepts used in data analysis and database management.

## Topics Covered

- Basic `SELECT` statements
- Filtering data with `WHERE` + ( `IN`, `AND`, `OR`, `LIKE`, `BETWEEN`, `IS NULL`)
- Sorting results using `ORDER BY`
- Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- Grouping data with `GROUP BY`
- Joining multiple tables using `INNER JOIN` and `LEFT JOIN`
- Sales and revenue analysis
- Customer order analysis


## Purpose

This repository serves as a record of my SQL learning journey and a reference for common SQL queries and business reporting tasks. I plan to add more advanced topics such as subqueries, window functions, Common Table Expressions (CTEs), stored procedures, triggers, and database optimization.
